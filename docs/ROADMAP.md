# Roadmap

## Phase 0 — foundation (active)

- Repository architecture, board record, protocol, simulator, tests.
- Real host telemetry vertical slice.
- Native USB transport build and physical bidirectional validation.
- Physical board revision and display/touch validation remain open.

## Phase 1 — functional dock

- ST7796S + FT6336U LVGL board bring-up.
- USB host serial adapter and secure pairing.
- Device state cache, reconnection, diagnostics, and settings.
- macOS permission onboarding and signed background service.

## Phase 2 — productivity

- Persistent workspaces, focus mode, quick capture, attention center.
- Contextual controls and configurable physical input abstraction.

## Phase 3 — personal intelligence

- Provider-independent AI, voice capture, memory, retrieval, and calendar.

## Phase 4 — agents and approvals

- Agent registry, operation-bound physical approval, workflows, and engineering adapters.

## Phase 5 — hardware expansion

- GPIO expander, encoders, keys, NFC, audio, enclosure RGB, and optional sensors.

## Phase 6 — hardening

- Threat review, OTA/recovery, resource optimization, deployment, and hardware qualification.
